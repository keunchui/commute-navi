📖 사용 안내 · 홈 화면 추가 · API 키

① 브라우저 GPS는 HTTPS(또는 localhost)에서만

휴대폰 브라우저는 보안 연결이 아니면 위치를 주지 않습니다. file://로 파일을 열면 위치가 잡히지 않아 테스트 출발지로 자동 대체됩니다. HTTPS 주소로 열거나, 같은 와이파이의 PC에서 python -m http.server로 띄우면 위치가 동작합니다. 파일을 Netlify Drop·GitHub Pages 같은 무료 HTTPS 호스팅에 올려 열면 폰에서도 GPS와 앱 실행이 모두 가장 매끄럽습니다.

② Android 홈 화면에 추가

  1. Chrome에서 이 페이지를 엽니다.
  2. 오른쪽 위 ⋮ → 홈 화면에 추가 (또는 '앱 설치').
  3. 홈 화면의 아이콘을 누르면 주소창 없이 전체 화면으로 열립니다.

③ 앱이 안 열릴 때

카카오톡·인스타그램 같은 인앱 브라우저는 tmap://, nmap:// 같은 앱 실행을 막는 경우가 많습니다. Chrome으로 열어 주세요. 앱이 설치되어 있지 않으면 카드 아래 앱 설치 링크로 설치할 수 있습니다.

④ 실시간 소요시간(선택)

⚙️ 설정에 API 키를 넣으면 갱신할 때마다 3사의 주행 시간·거리·통행료를 자동으로 받아 가장 빠른 길을 표시하고, 아래 버튼으로 바로 안내를 시작합니다. 키는 이 브라우저(localStorage)에만 저장되며 외부로 전송되지 않습니다.

  • TMAP: apis.openapi.sk.com/tmap/routes · App Key
  • 카카오모빌리티: apis-navi.kakaomobility.com/v1/directions · REST API 키
  • 네이버 클라우드: maps.apigw.ntruss.com/map-direction/v1/driving · Client ID/Secret

브라우저에서 외부 API를 직접 부르면 CORS로 막히는 경우가 있습니다. 이때는 설정의 CORS 프록시에 프록시 주소(https://프록시/?url={url})를 넣으면 됩니다. 프록시가 헤더를 전달해야 인증이 됩니다.

⑤ 참고

표시되는 시간은 각 사 API의 응답이며 실제 교통 상황과 다를 수 있습니다. 안전 운전을 위해 출발 전에만 조작하세요.
